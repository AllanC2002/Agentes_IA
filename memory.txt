# Stack principal
- Backend: FastAPI
- Servidor: uvicorn
- Frontend: HTML + CSS + JS vanilla
- Estructura típica:
  - main.py
  - index.html
  - style.css
# Convenciones

- El endpoint `/` devuelve `index.html` usando FileResponse.
- Los endpoints `/api/*` devuelven JSON usando JSONResponse.
- El frontend consume APIs usando fetch().
- Si el backend devuelve JSON se usa response.json().
- Nunca asignar objetos completos a textContent.

# Problemas frecuentes detectados

- Endpoints llamados desde frontend que no existen.
- Duplicación accidental de documentos HTML.
- Uso de YOUR_API_KEY sin reemplazar.
- Intentar mostrar objetos JSON directamente en textContent.
- No usar units=metric en OpenWeatherMap.
